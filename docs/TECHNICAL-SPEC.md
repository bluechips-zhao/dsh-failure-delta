## 采集算法

1. execute waterfall 中，在 next 前建立 PendingExecution，记录 startSeq、宿主候选目录、可信 Session、runner 候选。默认无文件预检等待；显式启用 profile 才允许有界、可取消的报告/元数据预检，等待自有读取结束后调用 next。读失败或不能在开始前取得证据则降级；不得无限等待、遗弃 I/O 或延误后假称原工具已开始。
2. next 恰好调用一次。禁止为了比较执行额外命令。finally 只清理已知无效项，不得改变原完成状态。
3. result 同步监听回调必须返回 undefined。验证规范值形状，按执行 token 去重；同步复制有上限的安全字段，随后排入有预算的处理队列。事件中不返回 Promise。
4. 工具错误、取消、未知 DTO、后台句柄产生可见运行状态；无规范 foreground 值不能解析成完整检查。
5. worker 解析、脱敏、计算证据、存储派生快照，再提交单调 revision。所有处理只影响插件自身。

Pending 采用有界 Map；token 不序列化，不假设 symbol 可用于 WeakMap。内部 token 生命周期按 result 或超时清理；清理导致失去开始证据时，只能降级，不能补造 startSeq。

## 报告与元数据资格

默认只消费原工具结果。runProfiles 可显式声明 runner、命令模式、报告路径、允许读取的配置/锁文件及运行时证据来源。声明不等于证实；运行时/环境未知时最多有限观察。

报告资格必须同时成立：

- 命令明确配置对应 reporter 与路径；执行坐标和实际目录已证实。
- DSH 文件提供者能证明工作区内规范包含关系，不依赖字符串前缀。
- 开始前报告不存在，结束后为本次独占新产物；固定已有文件不能靠 mtime 或相同长度证明新鲜。
- 无其他重叠运行使用该路径；读取前后身份/大小稳定，读取在预算内。
- 输入格式/schema 支持，结果清单及计数自洽，无截断或实体扩展。

推荐用户自行选择每次唯一的报告路径。插件不得删旧报告、改命令生成路径、执行配置、读外部 spillPath，或用用户声明绕过上述条件。报告失败回落到有限文本观察，并显示具体原因。

## 预算默认值

| 配置 | 默认 | 约束 |
|---|---:|---|
| maxInputBytesPerRun | 1 MiB | 64 KiB–8 MiB；UTF-8 字节计 |
| maxReportBytes | 4 MiB | 最高 16 MiB，超限不继续读取 |
| maxLines | 20,000 | 到限即标记局部观察 |
| maxDiagnostics | 1,000 | 保留 droppedCount |
| maxTestCases | 20,000 | 到限清单 incomplete |
| maxQueueRunsPerSession | 16 | 满时写丢失状态，不阻塞工具 |
| maxQueueBytesGlobal | 16 MiB | 与存储预算分别核算 |
| maxRunsPerSession / maxSessions | 100 / 32 | LRU 淘汰，保留健康计数 |
| maxStoreBytesGlobal | 64 MiB | 包含索引/快照估算，实测校准 |
| maxExcerptChars | 240 | 截断前后均脱敏，浏览器纯文本 |
| maxConfigFiles / maxConfigBytes | 32 / 128 KiB | 显式允许的总读取预算 |
| maxPendingExecutions | 256 | 超限丢失开始证据可见 |
| pendingTTL | 30 分钟 | 仅插件记录清理，不取消原工具 |
| rpcPageSize / rpcMaxBytes | 25 / 256 KiB | 单页最多 100 项；超限分页或明确截断 |
| maxReasonCodes | 16 | 多余原因聚合计数，不省略有限观察总标记 |

解析任务须支持预算中止与宿主销毁；I/O 不可无限悬挂。性能目标初值：1 MiB 受支持文本单次解析 p95 ≤100 ms，事件同步快照 p95 ≤5 ms（指定测试机器、冷/热样本分开）；未实测不得标 PASS。

## 对比门槛

basicSeriesKey 用于候选分组，不等于可比证据。完整可比要求必要目录、命令语义、范围、runner/schema、配置、运行时和环境证据匹配，且两端完整、报告新鲜。未知项输出 reasonCodes，不能用默认值代替已知。

差异字段分诊断 occurrences 与测试 cases，禁止混成“共修复 N 个”。百分比只在完整可比且单位相同、分母非零时展示，标题必须说明是观测变化而非修复率。首版可以不显示百分比，以类别计数为主。

## 查询能力

拟定工具名 failure_delta_query，参数为操作 list/get/compare/health 与可选 runId/baselineRunId；不得由模型传 sessionId 决定授权。返回有界脱敏 DTO 和 reasonCodes；按需调用不触发 shell。名称与 schema 必须在 D1 核对注册冲突。

Remote 同四项只读操作，Session 参数绑定必须使用官方宿主解析/权限路径，不能猜 HTTP API。输出分页游标绑定 Session/epoch；跨 epoch 游标过期，跨会话 runId 不泄露存在性。

请求参数须严格校验枚举、有限安全整数、字符串长度与未知字段；runId 最大 128 字符，游标最大 512 字符。同 Session 查询突发上限建议 8 次/秒并退避，不能通过超大 compare 输出绕过分页预算。取消只取消插件请求，不取消原检查。

短期解析输入快照可以含有原始受限输出，但只存在预算内处理队列，处理/失败/卸载后立即释放；禁止进入派生 store、console、Remote、fixture 自动保存或磁盘。摘录 240 字符、显示名称 160 字符、相对显示路径 240 字符，截断必须标识且不能参与语义身份。
