# 威胁模型与剩余风险

本插件不是安全边界，不保证阻止破坏、证明修复或发现所有错误。它保护的是“对失败变化的陈述不要超出证据”，并尽量不制造新的日志泄露和宿主故障。

信任域：DSH 宿主与授权机制属于可信计算基；工具输出、工作区文件、测试名称和报告不可信；同进程其他插件可影响结果与监听顺序，无法在本插件内完全约束。

| ID | 威胁/失败 | 防护与降级 | 剩余风险 |
|---|---|---|---|
| T-001 | 截断/空输出误认修复 | 独立完整性、有限观察、零匹配不成功 | 受支持解析器仍可能漏未知格式 |
| T-002 | 过滤/跳过/范围缩小 | 范围指纹、显式 case 状态、缺失未确认 | runner 不报告全部 collection 时只能降级 |
| T-003 | 陈旧报告冒充新结果 | 开始不存在、独占新路径、稳定读取 | 不同写入者替换仍需宿主身份能力；无法证明就不接纳 |
| T-004 | 报告路径越界/符号链接 | 提供者规范包含关系、执行坐标校验 | TOCTOU 无法闭合则报告不合格；不改用字符串判断 |
| T-005 | XML 实体/深度炸弹 | 禁 DTD/实体/网络，大小深度节点预算 | 库实现漏洞需版本审计 |
| T-006 | 凭据、PII 与源码泄露 | 不存原日志、短摘录脱敏、无上传 | 脱敏不是所有秘密的完备识别器 |
| T-007 | 提示注入/HTML/OSC | 查询明示数据、文本渲染、去控制符 | 用户主动打开原日志仍可见不可信文本 |
| T-008 | 跨会话 runId/RPC 越权 | 每次 Session 授权与所属校验、统一错误 | 依赖 DSH 官方授权正确性 |
| T-009 | 重名测试/指纹碰撞/过度规范化 | 域分离 HMAC、多重集合、冲突标歧义 | 语义身份不等于跨 runner 完美匹配 |
| T-010 | 并发完成乱序/环境漂移 | startSeq 基线，重叠降级，必要元数据证据 | 不提供因果证书 |
| T-011 | 内存/CPU/队列耗尽 | 有界快照、预算中止、可见丢失计数 | 预算导致观察覆盖降低，不能隐藏 |
| T-012 | 记录器失败改变工具行为 | 旁路隔离、next 一次、原异常透传 | 同进程进程级崩溃无法隔离 |
| T-013 | 重启/淘汰造成假历史 | epoch 清空、expired-run、健康计数 | v1 故意没有跨进程历史 |
| T-014 | 上游漂移/另一策略替换结果 | pinned preflight、fresh-profile 测试、明确观察最终规范值 | 无法证明模型所见文本或其他插件未篡改，不能声称端到端完整性 |

## 默认最小权限

无网络客户端、无遥测、无 shell 调用、无工作区写入、无自动报告/配置读取。显式开启的读取仅用于已声明文件，走 DSH 文件提供者，不继承 unrestricted 本机 fs 权限。读取失败降级，不请求扩大范围或自动关闭 sandbox。

## 安全验收原则

跨会话、路径越界、实体扩展或原工具行为改变任一未通过，停止相应功能交付。UI 可缺席但必须标 partial，不得以核心测试代替 Web 安全验证。解析结果的正确性必须由恶意/边界 fixture 与真实 runner 双重证明。

官方 DSH 是实验性软件，依赖其权限/隔离不意味着已经通过安全审计。公开宿主、远程 provider、外部环境与发布必须各自获得证据和授权。
